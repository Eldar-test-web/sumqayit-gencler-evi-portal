# Instagram fotolari

Bu qovluq `sumqayit_genclerevi` Instagram hesabindan goturulen rəsmi fotolar üçündür.

Sayt bu faylları avtomatik əsas götürür (tapılmadıqda real könüllülük fotoları olan
yer tutuculara keçir). Fayl adları:

- bina.jpg      - Gənclər Evinin binası (göndərilən bina fotosu bura: bina.jpg)
- bina-ic.jpg   - Bina girişi / daxili məkan
- telim-1.jpg  - Təlim / seminar
- telim-2.jpg  - Komanda işi / workshop
- robot.jpg    - Robotexnika məşğələsi
- debat.jpg    - Debat / müzakirə
- konullu-1.jpg - Könüllülər (yemək qutuları / sahə işi)
- konullu-2.jpg - Könüllü anı
- konullu-3.jpg - Yardım qutuları ilə könüllülər
- tedbir-1.jpg - Tədbir / icma
- tedbir-2.jpg - İcma tədbiri
- seminar.jpg  - Seminar zalı

QEYD: Instagram anonim yükləməyə icazə vermir (401 + login divarı, bütün viewer
saytlar blokludur). Buna görə rəsmi fotolar istifadəçi tərəfindən bura əlavə
olunmalıdır. Bina fotosunu çatda göndərilən şəkli `bina.jpg` adı ilə bura yadda
saxlamaq kifayətdir, sayt avtomatik onu göstərəcək.
